Керування

    
WASD — рух · Space — стрибок · Shift — біг / вниз у польоті
F або 2×Space — політ · E — інвентар · R — їсти · F2 — скріншот
ЛКМ — ламати / бити · ПКМ — ставити / використати
ПКМ по TNT / Цар-бомбі — підпалити · по ліжку — спати
ПКМ по важелю / кнопці — редстоун · по монітору — ПК · по жителю — чат з ШІ
Середня кнопка — взяти блок · Колесо / 1-9 — хотбар
F5 — вид від третьої особи · ПКМ по КамАЗу — сісти (W/S газ, A/D кермо, Space гальмо, H сигнал, X вийти)
ПКМ по пса зі свининою — приручити · ПКМ по дверях — відкрити · по табличці — текст
T — чат (мультиплеєр) · F5 — вид з-за спини
